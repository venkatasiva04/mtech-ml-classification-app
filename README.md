Classification Model Benchmark & Deployment

Problem Statement
The objective of this project is to implement, evaluate, and benchmark six distinct machine learning classification algorithms on a high-dimensional medical diagnostic dataset. The task requires evaluating each model across six standard performance metrics (Accuracy, AUC, Precision, Recall, F1 Score, and Matthews Correlation Coefficient) and deploying an interactive model inference dashboard using Streamlit Community Cloud.

Dataset Description
Dataset Name: Breast Cancer Wisconsin Diagnostic Dataset (UCI / Scikit-Learn)

Total Instances: 569 instances (Train: 455, Test: 114)

Total Features: 30 continuous real-valued feature inputs calculated from digitized fine needle aspirate (FNA) images of breast masses (e.g., mean radius, texture, perimeter, area, smoothness, concavity, symmetry).

Target Variable: Binary classification — 0 (Malignant) vs. 1 (Benign).

Split Ratio: 80% Training, 20% Testing (Stratified).
